계정

    Claude 구독 추가

    로그인 창은 시크릿 모드라 계정마다 따로 로그인할 수 있습니다. Google 로그인이 막히면 이메일 인증 코드 로그인을 쓰세요.

    sessionKey 직접 입력

    브라우저에서 claude.ai 접속 → 개발자 도구(F12) → Application → Cookies → sessionKey 값

    Claude Code 인증 파일

    Claude Code CLI로 로그인한 경우 사용합니다. 파일은 읽기만 합니다.

    ChatGPT 구독 추가

    ChatGPT 요금제에 포함된 Codex의 5시간·주간 사용 한도를 보여줍니다. 일반 채팅 메시지 한도는 OpenAI가 조회 수단을 제공하지 않아 표시할 수 없습니다.

    API 사용액 추가

    일반 API 키가 아닌 Admin 키가 필요합니다 (Claude Console → Settings → Admin keys / OpenAI Platform → Organization → Admin keys). 남은 크레딧 잔액은 두 서비스 모두 API로 조회할 수 없어서 이번 달 사용액을 보여주고, 월 예산을 넣으면 예산 대비 비율과 알림을 줍니다.

    표시 · 알림

    칸을 누른 뒤 원하는 키 조합(예: Ctrl+Shift+U)을 누르세요. Backspace를 누르면 단축키를 끕니다.
